Checkers: Deluxe Edition (Rust) 🦀
A professional Checkers game built with Rust, focusing on high performance and a challenging AI.

🚀 Why This Project?
This project is more than just a game; it's a showcase of Rust's power in handling complex algorithms:

Extreme Speed: Utilizes Bitboards technology for board representation, allowing move calculations to happen in milliseconds.

Advanced AI: A built-in engine using the Minimax algorithm with Alpha-Beta Pruning, capable of thinking several steps ahead to ensure the best possible move.

Classic Design: A simple and attractive graphical interface (Wooden Theme) powered by the Macroquad library.

🛠️ Features
✅ Game Modes: Play Player vs Player (PvP) or Player vs AI (PvA).

✅ Difficulty Levels: Adjustable AI thinking time via the settings menu.

✅ Professional Rules: Supports the "Force Capture" rule (customizable).

✅ Utility Tools: Includes Undo functionality and the ability to Flip the board.

✅ Sound Effects: Integrated audio for movements and captures.

💻 How to Run
If you have Rust installed, simply run the following command in the project directory:

Bash
cargo run --release
